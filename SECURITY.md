# Política de seguridad

## Versiones compatibles

La versión publicada desde la rama `main` es la única versión compatible.

## Reportar un problema

Los problemas de seguridad del sitio pueden reportarse de forma privada a:

`luzgraciela13.colaborations@gmail.com`

Incluir, cuando sea posible:

- Página o archivo afectado.
- Descripción clara del problema.
- Pasos para reproducirlo sin exponer datos de terceros.
- Impacto observado.

No publicar credenciales, tokens, direcciones privadas ni información personal en un issue público.

## Alcance

Este repositorio genera un sitio estático. No procesa contraseñas, pagos ni datos enviados mediante formularios. Los enlaces de contacto abren servicios externos como correo, GitHub y LinkedIn.
