## Overview

Game development is a personal project I use to practice programming from a visual and interactive perspective. Through 2D minigames, I explore mechanics, state management, interfaces, and scene organization in Godot.

## Technical purpose

The goal is not to present these prototypes as finished commercial products, but to demonstrate self-directed learning and the ability to apply programming concepts in an environment beyond backend development and networking.

## Activities

- Created and organized 2D scenes.
- Programmed movement, rules, and events.
- Used signals to communicate between components.
- Managed player and game states.
- Designed simple interfaces.
- Applied object-oriented programming concepts.
- Performed iterative testing and corrected unexpected behavior.

## Connection to my profile

Working with games strengthens skills I also apply to other projects: breaking down problems, designing components, interpreting visual feedback, debugging, and independently learning new tools.

## Next steps

The collection will continue to grow with better-documented prototypes, screenshots, and selected public repositories. Only projects with a clear structure and a functional version suitable for evaluation will be published.
